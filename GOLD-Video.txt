10. What is speculative execution in Hadoop?

In Hadoop during Speculative execution, a certain number of duplicate tasks are launched. On a different slave node, mutiple copies of same map or reduce task can be executed using speculative execution.

ChatGPT Answer:
If one Map or Reduce task is running unusually slowly, Hadoop starts another copy of the same task on a different node. Whichever copy finishes first is used, and the slower copy is stopped.


11. What is High Availability and Federation in Hadoop?

The high availability feature in hadoop ensure the availiability of hadoop cluste without any downtime, even in unfavorable conditions like NameNode failure, DataNode failure, machine crash , etc. It means if the machine crashes, data will be accessible from another path.

HDFS Federation improves the existing HDFS architecture through a clear separation of namespace and storage , enabling generic block storage layer. It enable support for multiple namspace in the cluster to improce scalability and isolation.
